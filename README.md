# FinPulse Pharma

Интерактивный прототип финансового контура для фарм-производства.

## Что реализовано

- сверка ОПиУ, Баланса и ДДС;
- автоматическое резюме и сигналы финансовых рисков;
- чек-лист и авто-валидатор закрытия месяца;
- калькулятор точки безубыточности, приведенной стоимости, срока окупаемости и доли прибыли в цене;
- анализ сроков хранения запасов, оплаты покупателями, оплаты поставщикам и полного финансового цикла;
- сценарный расчет влияния курса, сырья и логистики;
- адаптивная темная тема с анимированными цветовыми контурами.

Все показатели в текущей версии являются демонстрационными. Для рабочего импорта нужны структура выгрузки 1С, правила маппинга счетов и контрольные соотношения компании.

## Запуск

```powershell
pnpm install
pnpm dev
```

Сборка для публикации:

```powershell
pnpm build
```
